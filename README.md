## Deploying to GitHub Pages (Personal Account: `jdsr26`)

To publish this website on your personal GitHub account (`jdsr26`):

1. **Create a New Repository**:
   - Log into your personal GitHub account (`jdsr26`).
   - Create a new public repository named `jdsr26.github.io` (or `portfolio`).

2. **Push the Files**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - AI Engineer Portfolio Website"
   git branch -M main
   git remote add origin https://github.com/jdsr26/jdsr26.github.io.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to **Settings > Pages** in your repository.
   - Under **Source**, select `Deploy from a branch` and set the branch to `main` (`/root`).
   - Click **Save**. Your website will be live at `https://jdsr26.github.io` in 1-2 minutes!
